# ⚡ Charge Stockholm

PWA с ценами и свободными местами на зарядных станциях **Alecta** в Стокгольме.
Без серверов, API-ключей и платных сервисов: GitHub Actions каждые 30 минут забирает данные
из открытого **Spirii AFIR API** и публикует сайт на GitHub Pages.

**Станции (DC):** Nacka Strand, Solna Centrum, Bredden Öst, Bredden Väst, Barkarby,
Värmdö Marknad, Värmdö Köpcenter, Flygfyren. Список задаётся в `LOCATIONS` в `scripts/parser.py`.

## Возможности

- Текущая цена за кВт·ч с учётом ночных и дневных тарифов
- Расписание тарифа по часам и дополнительные сборы (например, +5 kr/мин после 120 мин)
- Свободные, занятые и неработающие точки по каждой станции
- Сортировка по цене, свободным местам, мощности и расстоянию
- Избранные станции, хранятся на устройстве
- История цены и занятости до 365 дней, графики за 24 ч, 7 и 30 дней и за год
- Средняя цена и доля свободных мест по часам суток
- Калькулятор: стоимость сейчас и в самый дешёвый час, примерное время зарядки
- Маршрут в Google Maps по точным координатам из API
- Тёмная тема, установка на iPhone и Android, офлайн-режим с последними данными

## Структура

```
.github/workflows/monitor.yml   расписание, тесты, сбор данных, деплой Pages
scripts/parser.py               сборщик (только стандартная библиотека Python)
scripts/test_parser.py          тесты
scripts/fixtures/               реальный ответ Spirii (срез по Alecta) для тестов
docs/                           сайт (PWA): index.html, app.js, style.css, sw.js, manifest.json, icons/
docs/data/                      генерируется: latest.json, history.json (в git не хранится)
```

## Запуск на GitHub

1. Запушить репозиторий на GitHub. Репозиторий должен быть публичным: Pages на бесплатном плане работает только с публичными.
2. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. **Actions → Monitor charging prices → Run workflow**. Workflow также запускается сам при пуше в `main`.
4. Через 1–2 минуты сайт откроется по адресу `https://<USERNAME>.github.io/charge-stockholm/`.

Дальше workflow запускается сам на 7-й и 37-й минуте каждого часа (UTC).

**Где хранятся данные.** История лежит в ветке `data`, в одном коммите, который каждый раз
перезаписывается. Так `main` не разрастается от 48 коммитов в сутки. Ветку `data` не удаляйте:
в ней вся накопленная история.

### Установка на телефон

- **iPhone:** открыть сайт в Safari → «Поделиться» → «На экран „Домой“».
- **Android:** Chrome → меню → «Установить приложение».

## Локально

```bash
python3 scripts/parser.py                          # данные в docs/data/
python3 -m http.server 8000 --directory docs       # http://localhost:8000
python3 -m unittest discover -s scripts            # тесты
```

## Как читаются тарифы

Spirii отдаёт для каждой точки тариф `adHoc` в SEK, это список `energyPrice`:

| Запись | Как трактуется |
|---|---|
| `pricePerKWh` с окном времени (`00:00–07:00`) | цена в этом окне (ночной тариф) |
| `pricePerKWh` без окна | цена по умолчанию в остальное время |
| `pricePerMinute` + `timeBasedApplicability.fromMinute` | доп. сбор (плата за простой после N минут) |
| `taxIncluded: false` + `taxRate` | цена пересчитывается с НДС |
| неизвестный НДС / неподдерживаемое условие | пропускается, предупреждение в логе |

Обновления тарифа из потока статусов (`energyRateUpdate`) имеют приоритет над таблицей.
Если у точек одной станции разные тарифы, показывается мин–макс текущей цены.

## Ограничения

- Показывается цена **разовой зарядки** по AFIR. В приложениях операторов, по подпискам и картам цена может отличаться. Перед оплатой сверяйтесь с ценой на месте.
- Станции ищутся по точному названию `Alecta F - <название>`. Если Spirii переименует сайты, workflow напишет `WARNING: locations not found`, и тогда нужно поправить `LOCATIONS` / `SITE_PREFIX` в `scripts/parser.py`.
- GitHub запускает cron с задержкой от нескольких минут до получаса и может приостановить расписание в репозитории без активности 60 дней. Тогда нажмите **Enable workflow** во вкладке Actions.
- Если API недоступен, запуск завершается ошибкой, а на сайте остаются предыдущие данные с пометкой «данные устарели».
- Геолокация нужна только для сортировки по расстоянию и никуда не отправляется.

Необязательные переменные (**Settings → Secrets and variables → Actions → Variables**):
`SPIRII_CUSTOMER_IDS`, `SPIRII_CPO_ID`. Они сужают запрос к API, по умолчанию не нужны.
